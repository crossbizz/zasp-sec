Zasp UI asset sources

Base AWS, Azure, GCP, GitHub, MCP, OpenAI, Anthropic SVGs: supplied kit; included Devicon/LobeHub license notices.
Dark AWS, GitHub, MCP and OpenAI SVGs: explicit monochrome variants of the kit's currentColor paths.
Kubernetes, Okta, Salesforce, Slack, GitLab SVGs: https://github.com/devicons/devicon/tree/master/icons ; devicon-MIT.txt.
Atlassian and Databricks SVGs: https://github.com/gilbarbara/logos/tree/main/logos ; logos-CC0.txt.
Zasp wordmarks: supplied Zasp Logo Design.zip; 4.png for light mode and 3.png for dark mode. SVG files frame the unmodified source PNGs; public/brand/SOURCES.json records their SHA-256 digests and viewports.
