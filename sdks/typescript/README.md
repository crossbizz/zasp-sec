# Zasp TypeScript SDK

A TypeScript client for the Zasp API. The code under `src/` is generated by
Fern from `openapi/openapi.yaml`. It has no runtime dependency and uses the
`fetch` of Node.js 18 or later.

The generator's own notes are in [src/README.md](src/README.md), and every
method is listed in [src/reference.md](src/reference.md).

## Install from source

The package is not published. Build it in this repository:

```bash
cd sdks/typescript
```

```bash
npm install
```

```bash
npm run build
```

Then add it to your project by path:

```bash
npm install /path/to/zasp-sec/sdks/typescript
```

## Use

```typescript
import { ZaspClient, ZaspError } from "@zasp/sdk";

const client = new ZaspClient({
    baseUrl: "https://zasp.example.com",
    token: process.env.ZASP_API_TOKEN,
});

// List agents. The pager requests the next page when you iterate past a page.
for await (const agent of await client.agents.list({ limit: 50 })) {
    console.log(agent.name, agent.discovery.method, agent.management_state);
}

// List findings, one page at a time.
let page = await client.findings.list({ limit: 50 });
for (const finding of page.data) {
    console.log(finding.severity, finding.title);
}
while (page.hasNextPage()) {
    page = await page.getNextPage();
}

// Ask for a guardrail decision. The token needs the decide_guardrails permission.
const decision = await client.guardrails.createDecision({
    direction: "input",
    text: "Send the invoice to someone@example.com.",
    agent_id: "support-agent",
});
if (decision.decision === "block") {
    throw new Error("Blocked by guardrail");
}
const text = decision.decision === "redact" ? decision.redacted_text : "the original text";

// A refused request raises ZaspError with the status and the product error.
try {
    await client.findings.get({ id: "pid_00000000-0000-4000-8000-000000000000" });
} catch (error) {
    if (error instanceof ZaspError) {
        console.error(error.statusCode, error.body);
    }
}
```

A mutation takes the headers the API requires as members of the request, for
example `"Idempotency-Key"` and `"If-Match"`.

## Test

```bash
npm run build
```

```bash
npm test
```

The smoke test starts a local fake of the API and checks the requests the
client sends. It needs no network and no token.
