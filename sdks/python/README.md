# Zasp Python SDK

A Python client for the Zasp API. The package under `src/zasp/` is generated by
Fern from `openapi/openapi.yaml`. It needs Python 3.9 or later, `httpx` and
`pydantic`.

The generator's own notes are in [src/zasp/README.md](src/zasp/README.md), and
every method is listed in [src/zasp/reference.md](src/zasp/reference.md).

## Install from source

The package is not published. Install it from this repository:

```bash
pip install ./sdks/python
```

## Use

```python
import os

from zasp import Zasp
from zasp.core.api_error import ApiError

client = Zasp(
    base_url="https://zasp.example.com",
    token=os.environ["ZASP_API_TOKEN"],
)

# List agents. The pager requests the next page when you iterate past a page.
for agent in client.agents.list(limit=50):
    print(agent.name, agent.discovery.method, agent.management_state)

# List findings.
for finding in client.findings.list(limit=50):
    print(finding.severity, finding.title)

# Ask for a guardrail decision. The token needs the decide_guardrails permission.
decision = client.guardrails.create_decision(
    direction="input",
    text="Send the invoice to someone@example.com.",
    agent_id="support-agent",
)
if decision.decision == "block":
    raise RuntimeError("Blocked by guardrail")
text = decision.redacted_text if decision.decision == "redact" else "the original text"

# A refused request raises ApiError with the status and the product error.
try:
    client.findings.get(id="pid_00000000-0000-4000-8000-000000000000")
except ApiError as error:
    print(error.status_code, error.body)
```

`AsyncZasp` is the same client with `async` methods.

Without `token`, the client reads the environment variable `ZASP_API_TOKEN`.

## Test

```bash
pip install "./sdks/python[test]"
```

```bash
cd sdks/python
```

```bash
python -m pytest tests
```

The smoke test starts a local fake of the API and checks the requests the
client sends. It needs no network and no token.
