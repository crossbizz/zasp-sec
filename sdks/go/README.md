# Zasp Go SDK

A Go client for the Zasp API. The code in this module is generated by Fern from
`openapi/openapi.yaml`. It needs Go 1.21 or later.

Every method is listed in [reference.md](reference.md).

This README, `go.mod`, `go.sum` and `smoke_test.go` are not generated. They are
listed in `.fernignore`, so generating the SDK again keeps them.

## Install from source

The module path is `github.com/zasp-ai/zasp-sec/sdks/go`. The module is not
published as a tagged release, so point your module at a checkout of this
repository:

```bash
go mod edit -replace github.com/zasp-ai/zasp-sec/sdks/go=/path/to/zasp-sec/sdks/go
```

```bash
go get github.com/zasp-ai/zasp-sec/sdks/go
```

## Use

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"log"
	"os"

	zasp "github.com/zasp-ai/zasp-sec/sdks/go"
	"github.com/zasp-ai/zasp-sec/sdks/go/client"
	"github.com/zasp-ai/zasp-sec/sdks/go/option"
)

func main() {
	ctx := context.Background()
	c := client.NewClient(
		option.WithBaseURL("https://zasp.example.com"),
		option.WithToken(os.Getenv("ZASP_API_TOKEN")),
	)

	// List agents. The iterator requests the next page when a page is used up.
	limit := 50
	agents, err := c.Agents.List(ctx, &zasp.ListAgentsRequest{Limit: &limit})
	if err != nil {
		log.Fatal(err)
	}
	iterator := agents.Iterator()
	for iterator.Next(ctx) {
		agent := iterator.Current()
		fmt.Println(agent.GetName(), agent.GetManagementState())
	}
	if err := iterator.Err(); err != nil {
		log.Fatal(err)
	}

	// List findings, first page.
	findings, err := c.Findings.List(ctx, &zasp.ListFindingsRequest{Limit: &limit})
	if err != nil {
		log.Fatal(err)
	}
	for _, finding := range findings.Results {
		fmt.Println(finding.GetSeverity(), finding.GetTitle())
	}

	// Ask for a guardrail decision. The token needs the decide_guardrails permission.
	agentID := "support-agent"
	decision, err := c.Guardrails.CreateDecision(ctx, &zasp.GuardrailInteraction{
		Direction: zasp.GuardrailInteractionDirectionInput,
		Text:      "Send the invoice to someone@example.com.",
		AgentID:   &agentID,
	})
	if err != nil {
		// A refused request is a typed error with the product error as its body.
		var unauthorized *zasp.UnauthorizedError
		if errors.As(err, &unauthorized) {
			log.Fatalf("token refused: %s", unauthorized.Body.GetCode())
		}
		log.Fatal(err)
	}
	switch decision.GetDecision() {
	case zasp.GuardrailDecisionDecisionBlock:
		log.Fatal("blocked by guardrail")
	case zasp.GuardrailDecisionDecisionRedact:
		fmt.Println(*decision.GetRedactedText())
	}
}
```

## Test

```bash
cd sdks/go
```

```bash
go test ./...
```

The smoke test starts a local fake of the API and checks the requests the
client sends. It needs no network and no token.
