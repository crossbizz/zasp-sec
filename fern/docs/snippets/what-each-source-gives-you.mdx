Every source gives you an inventory, ownership, the general findings, attack paths, the AI bill of materials and evidence. Some things depend on what the provider exposes and on what is built today.

How to read the table:

- The general findings (an agent with no owner, a human credential, a shared credential, reach from untrusted input to production, and the like) are raised for an agent of any source, wherever the facts they need were read.
- The findings about MCP servers are raised on the agents that use a server, for every source that records which agent uses which server.
- "None" under activity means the agent's activity is unknown, not that it is inactive. Two things give activity for an agent of any source: routing its traffic through the [hosted gateway](/concepts/guardrails-and-gateway), and the optional runtime sensor.
- Red team tests, guardrails, the hosted gateway and compliance evidence do not depend on the source.
- Remediation actions exist for AWS only today. A finding of any other source is fixed at the provider, by following the fix the finding names.
