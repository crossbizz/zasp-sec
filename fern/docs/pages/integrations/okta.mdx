## What is found

| Record | How |
| --- | --- |
| AI applications | Applications of the tenant that are known AI products or assistants |
| Applications and service principals | The tenant's applications |
| Users and groups | The directory, to say who is assigned to an AI application |
| Structure | The tenant |

An AI application connected to the tenant is an agent your organization uses without running it. It appears on the Agents page with the source of the tenant.

| | |

| Findings specific to it | None |

The general findings, attack paths, red team tests, guardrails, the hosted gateway and compliance evidence are the same for every source. All sources side by side: [What each source gives you](/integrations/overview#what-each-source-gives-you).

## What you grant

A read-only OAuth authorization with these scopes:

| Scope | Used for |
| --- | --- |
| `okta.apps.read` | Applications |
| `okta.groups.read` | Groups |
| `okta.users.read` | Users |
| `offline_access` | Syncing later without a person present |

Authorize with an account that may grant them, and restrict that account to this purpose.

## What your operator does

The operator creates an Okta application once and configures it in the deployment. Every tenant then connects by a sign-in. Nothing is stored per tenant outside the product.

## Configure

| Field | Value |
| --- | --- |
| Integration name | A name you will recognise |
| Okta issuer | Your tenant's address, `https://<tenant>.okta.com` |

Open the integration and authorize. You continue on Okta and sign in. Authorization verifies the issuer, the subject and the scopes, and reads one page of the directory.

After authorization the integration shows the Okta tenant and the directory scopes.

<Note>
This integration secures your Okta directory integration. It is separate from how members sign in to Zasp.
</Note>

## Limits to know

- An application is recognised as an AI application from its label, against a catalog of known products. An application the catalog does not know is listed as an ordinary application.

## Status

This connector has not been run against a real Okta tenant. It was tested against recorded API shapes.
