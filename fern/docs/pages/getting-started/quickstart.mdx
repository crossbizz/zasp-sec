This page is the short path. It assumes Zasp is running and you have an invitation. The [User guide](/user-guide) covers every step in full.

## Before you start

You need two things, whatever you connect:

- the address of the product, written here as `https://zasp.example.com`;
- an invitation to it.

Choose a configured provider that holds your agents. Your operator can enable a supported provider in Nango or create a connection reference for your tenant.

## 1. Sign in

Follow the invitation email, then choose **Sign in**. If the top bar shows a scope selector, choose the Environment you want to work in.

## 2. Connect your first source

<Note>
No source to connect yet? Ask your operator to seed demo data: `./zasp demo seed --email <your address>`. You get an Environment of its own with a fictional company's agents, findings, MCP servers and attack paths, which you open with your own sign-in. Its integrations are named `Demo: …`, and it can be removed again. The [Administrator guide](/administrator-guide#demo-data) has the details.
</Note>

Open **Integrations**. **Add a source** shows the supported providers configured in the Nango environment connected to your deployment. If a provider is missing, ask your operator to check its integration key and collector configuration. [Administrator setup](/administrator-guide#set-up-nango-in-this-cluster)

1. Choose your provider and enter the tenant identifier requested by its form.
2. When the form asks for a Nango connection, enter the `ref:nango/connection/<id>` supplied by your operator. Nango holds the provider credentials.
3. Choose **Save integration**. If the integration offers provider sign-in, start it, choose **Continue to provider**, and complete authorization in the new tab. Return to the original Zasp tab and choose **Finish sign-in**.

Zasp can discover AI apps and agents from Anthropic, Atlassian, Databricks, GitLab, Google Workspace, OpenAI, ServiceNow and Slack when their adapters are configured. [SaaS platforms](/integrations/saas-platforms)

## 3. Authorize and sync

These steps are the same for every source.

<Steps>
  <Step title="Authorize">
    Open the integration from **Configured integrations** and choose the authorize button. It names the provider. You may be asked to sign in again.
  </Step>
  <Step title="Sync">
    Choose **Sync inventory now**. **Sync history** shows the sync and the number of records it discovered.
  </Step>
  <Step title="Read coverage">
    If the integration shows **Agent discovery coverage**, each line names something the sync could not read and what to change. A coverage gap is not a failure.
  </Step>
</Steps>

## 4. Read what was found

<Steps>
  <Step title="Open Agents">
    Choose **Unmanaged**. These are the agents nobody has claimed. Open one and read **How it was found**.
  </Step>
  <Step title="Open Tools & MCP">
    If your source lists MCP servers, approve or block each one.
  </Step>
  <Step title="Open Findings">
    Open the first critical finding and read it from **Why** to **Verify**.
  </Step>
</Steps>

## Make a first API call

Create a token: open **API Access**, choose **Create API token**, choose **Read the Environment (view)**, save, reveal the token and copy it.

Put the token and the address in your shell:

```bash
export ZASP_API_TOKEN="<the token you copied>"
```

```bash
export ZASP_URL="https://zasp.example.com"
```

List the agents of the Environment:

<CodeBlocks>
```bash title="curl"
curl -sS "$ZASP_URL/api/v1/agents?limit=50" -H "Authorization: Bearer $ZASP_API_TOKEN"
```

```python title="Python"
import os

from zasp import Zasp

client = Zasp(base_url=os.environ["ZASP_URL"], token=os.environ["ZASP_API_TOKEN"])
for agent in client.agents.list(limit=50):
    print(agent.name, agent.provider, agent.discovery.method, agent.management_state)
```

```typescript title="TypeScript"
import { ZaspClient } from "@zasp/sdk";

const client = new ZaspClient({ baseUrl: process.env.ZASP_URL!, token: process.env.ZASP_API_TOKEN });
for await (const agent of await client.agents.list({ limit: 50 })) {
    console.log(agent.name, agent.provider, agent.discovery.method, agent.management_state);
}
```

```go title="Go"
c := client.NewClient(option.WithBaseURL(os.Getenv("ZASP_URL")), option.WithToken(os.Getenv("ZASP_API_TOKEN")))
limit := 50
agents, err := c.Agents.List(ctx, &zasp.ListAgentsRequest{Limit: &limit})
if err != nil {
    log.Fatal(err)
}
iterator := agents.Iterator()
for iterator.Next(ctx) {
    fmt.Println(iterator.Current().GetName())
}
```
</CodeBlocks>

<Note>
The SDK calls on this page were run against a local fake of the API, not against a deployment. The `curl` command was not run in the authoring environment. The SDKs are installed from the repository: see [API tokens and SDKs](/guides/api-tokens-and-sdks).
</Note>
