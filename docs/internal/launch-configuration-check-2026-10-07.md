The command maps the same three supported Stytch aliases as `npm run api:start`, then invokes the API's complete configuration loader with the fixed `--check-config` flag. The installed API binary also accepts `agentsec-api --check-config`; direct binary use requires the existing `ZASP_` setting names.

The check validates configuration syntax, including enabled Temporal/OpenFGA settings and any present audit/compliance bundles. It does not construct clients, read credential files, start workers, open listeners, contact providers or perform migrations. Disabled runtime services can satisfy the loader's syntax contract; full production construction still requires the existing enabled/current runtime profile. This command does not replace that requirement or `/readyz`.
